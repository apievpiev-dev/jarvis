# Jarvis AI Assistant

Полнофункциональный AI-ассистент с голосовым интерфейсом, способный к самообучению и выполнению задач.

## Возможности

- 🎤 **Голосовое управление** - распознавание и синтез речи на русском языке
- 💬 **Текстовый интерфейс** - веб-чат с реальным временем
- 🧠 **AI-мозг** - обработка команд с помощью Phi-2
- ⚡ **Выполнение задач** - управление файлами, браузером, системой
- 🔧 **Работа с кодом** - анализ, модификация и генерация кода
- 📚 **Самообучение** - непрерывное улучшение и адаптация
- 🚀 **Горизонтальное масштабирование** - микросервисная архитектура

## Архитектура

```
jarvis/
├── services/           # Микросервисы
│   ├── voice-service/  # Распознавание и синтез речи
│   ├── brain-service/  # AI обработка команд
│   ├── task-service/   # Выполнение задач
│   ├── web-service/    # Веб-интерфейс
│   ├── code-service/   # Анализ и модификация кода
│   ├── learning-service/ # Самообучение
│   └── api-gateway/    # Маршрутизация сервисов
├── shared/             # Общие компоненты
│   ├── models/         # AI модели
│   ├── config/         # Конфигурации
│   ├── utils/          # Утилиты
│   └── memory/         # Данные обучения
├── docker-compose.yml  # Оркестрация контейнеров
├── k8s/               # Kubernetes манифесты
├── scripts/           # Скрипты развертывания
└── docs/              # Документация
```

## Быстрый старт

```bash
# Клонирование и настройка
git clone <repository>
cd jarvis

# Запуск всех сервисов
docker-compose up -d

# Веб-интерфейс
open http://localhost:3000
```

## Технологии

- **Backend**: Python + FastAPI
- **Frontend**: React + WebSocket
- **AI**: Whisper, Phi-2, TTS модели
- **База данных**: PostgreSQL, Redis
- **Контейнеризация**: Docker, Kubernetes
- **Мониторинг**: Prometheus, Grafana
